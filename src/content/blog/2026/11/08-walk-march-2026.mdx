After Pixey.org seemed to disable the Pixelfed API, it stayed this way, so I still don’t have a good way of retrieving the info I need for reposting photos easily from it here. But! My Firefox’s console history kept the quickly written script that I did for getting this info from the opened photo page there, and it still works!

<details>
<summary><u>My messy script, so I could reuse it from here the next time lol</u></summary>

```js
(() => {
	const photo = document.querySelector('.card-img-top');
	const data = {
		url: document.URL,
		"content": document.querySelector('.status-text')?.textContent,
		"created_at": document.querySelector('.media-body .timestamp')?.title,
		"reblogs_count": Number(document.querySelector('button:has(.fa-retweet)')?.textContent.trim() || 0),
		"favourites_count": parseInt(document.querySelector('button:has(.fa-heart)')?.textContent.trim(), 10),
		"edited_at": null,
		"replies_count": parseInt(document.querySelector('button:has(.fa-comment)')?.textContent.trim(), 10),
		"location": document.querySelector('.location')?.textContent.trim(),
		"photos": [
			{
				"url": document.querySelector('.card-img-top')?.src,
				"preview_url": photo?.src.replace('.jpg', '_thumb.jpg'),
				"width": Number(photo?.getAttribute('width')),
				"height": Number(photo?.getAttribute('height')),
				"alt": photo?.alt,
			},
		]
	};
	const fileName = `${document.URL.match(/\d+$/g)[0]}.json`;
	const blob = new Blob([JSON.stringify(data, null, 4)], {
		type: 'application/json'
	});

	const pseudoLink = document.createElement("a");
	pseudoLink.href = URL.createObjectURL(blob);
	pseudoLink.download = fileName;
	pseudoLink.click();

	return blob;
})();
```

## Trees

It was late March, and leaves started appearing on the trees. Although, for the bigger oaks it was harder to see the leaves on their big branches at the top sometimes.

![That’s a lot of branches.](pixelfed:941477030338784270)

Deeper in the forest, I encountered a few nicely-looking glades full of small flowers. I thought this one specifically was nice, with the hollow at the ground level. You could imagine some animal using it as their home:

![](pixelfed:941477902061096057)

Some of the older oaks in the forest are pretty tall! In the later [People](#people) section it will be easier to understand how tall they can be, but yeah, they can get tall.

![](pixelfed:941478665449807048)

There were occasional overgrown stumps, sometimes with something resembling inventory tags.

## Flowers

I don’t have a proper macro lens, but I like to make photos of small flowers like these.

![](pixelfed:941675490614478902)

Maybe I need to get something more dedicated to macro, although I wonder if you really need a proper flash setup for that? I enjoy not having to think about flashes or tripods, but maybe the way I shoot will be fine for those flowers, after all, they’re not quick insects that will run away from me.

![Lost a bit of detail in the petals here.](pixelfed:941675711621920890)

For the flowers on the trees and bushes, a macro lens is not as required, of course.

![](pixelfed:941675831594113170)
